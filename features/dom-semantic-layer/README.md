# DOM Semantic Layer

Scan native controls and supported accessible roles across the document and open
Shadow DOM. Resolve labels within their DOM tree. Exclude the companion, hidden
content, and editable contents from labels and section context. Observe document
and shadow-root mutations with debouncing.

Completion evidence contains at most 12 visible text items of at most 240
characters each. Collect alerts, statuses, selected tabs and current-page labels,
headings, then read-only paragraphs in
main or dialog regions. Exclude form paragraphs and form outputs. Remove current
form and editable values locally, including values echoed in result text, then
redact sensitive patterns. Never send raw HTML or editable contents.
