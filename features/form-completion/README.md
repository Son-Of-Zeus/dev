# Form Completion

Keep text input pending until the user explicitly says entry is done. Jev
classifies the utterance, including English and Hindi completion and negation.
Input presence and browser validity do not complete a field. An explanation or
clarification keeps the pending input. Do not run automatic model checks while
entry remains pending.

Explicit entry completion unlocks the next step and is separate from completion
of the full task. Select and click steps advance only after the corresponding
observed user action. Never fill, submit, or consent automatically.
