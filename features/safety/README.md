# Safety

The assistant guides only. The user clicks, enters data, selects, consents, and
submits. Do not send raw HTML, editable contents, or form values for planning or
selection. Remove current field values from completion evidence and redact
sensitive patterns before transmission or persistence.

Validate structured responses and decision memory. Save semantic descriptions,
never DOM IDs. Check each target against the live registry and discard outdated
answers. Keep provider keys in the backend. A Submit click or valid input does
not prove task completion. Only Jev's completion gate or explicit whole-task
confirmation after clarification can finish a task; Muse cannot bypass this gate.
